# 生产化重构审计与当前边界

日期：2026-10-24。审计基线：d7802de；开始时有未提交的工作台 UI/测试/CHANGELOG 改动，予以保留。实施契约见 [production-boundaries](../specs/tasks/production-boundaries.md)。本报告是当前代码审阅，不替代产品规格、验收或独立比较。

## 从用户结果推导架构

domimap 的核心价值是让人和 Agent 在不同会话中，重新核对同一份有适用范围的材料，并维护已有结论。因此架构的先后顺序应为：

1. 来源是谁、允许读什么、对应哪个版本。
2. 引用 ID 是否始终指向同一份可读证据。
3. 已确认写入能否在并发、错误和恢复中保留。
4. 搜索能否在限定预算内找到适用材料。
5. 接口、包和操作说明能否重复执行上述路径。

图、词法索引、嵌入和排序是可重建投影；人工知识、修订、审定和被引用证据是需要保存的数据。重构应围绕这条边界收敛，避免以文件拆分、更多框架或测试数量代替正确性。

## 数据与接口兼容

- 新 ev_id 为 `ev:` 后 64 位摘要；旧库中的 20 位 ID 原样可读，不批量重写历史。旧程序对新 ID 的链接生成不兼容，应用与数据库备份应配套回退。
- 最新来源指针使用现有 meta 表，和来源/证据更新同事务提交。反复捕获旧版本也不会错误地选取插入时间最新的版本。
- 已经被旧版覆盖的出处记录无法自动恢复。历史 ID 只保留当前库实际存在的原始记录，不伪造丢失历史。
- 证据 sha256 是最多 1 MiB 固化片段的摘要；超限仍显示 truncated。本轮没有把它包装成全文件内容版本，也未解决 PDF/DOCX 原始字节与解析后定位之间的全部对应关系。
- 知识备份新增 `domimap.kbackup.v2`；旧 v1 兼容恢复，但没有内容摘要。备份必须使用新目录；恢复必须使用新目标路径，含孤立 WAL/SHM/journal 的目标也拒绝。原始归档不会被覆盖。恢复发布依赖同目录原子硬链接，不支持的文件系统应明确报错，不退回覆盖式复制。
- 备份范围是 knowledge.db 的全部已知表，包含修订/审定/幂等/复核记录；不包含整个工作区的证据 blob、图和来源映射，不能因此宣称 R07 全部完成。 2026-10-26 起 `domimap export-workspace` 把证据库快照、blobs/、gens/、graph.json、coverage.json、各来源 manifest 与知识库（kbackup v2）打成一个带逐文件 sha256 的包；`restore-workspace` 逐成员校验后原子发布到新目录，active 代按新目录定位。查询日志默认不随包。Markdown/Obsidian 显式导入与冲突预览仍属 R07-02 待办。
- MCP 默认公布六个只读工具和进程内文本 API（写工具 kg_feedback 须 `serve --enable-write` 显式启用，经 MCP 转达的判定以非权威 agent_relay 来源落库，2026-10-26 mcp-write-gate），工具结构增加范围约束。字符串/布尔值不再被当整数接受；未知参数拒绝。查询最长 4096 字符、top_k 1–50、深度 0–8、遍历节点预算 1–2000；单帧限 1 Mi 字符、字符串请求 ID 限 256 字符。声明的 inputSchema 与运行时同源校验。完整协议版本协商及客户端生命周期尚未迁移。

## 验证与状态真实性

初始 `make verify` 在修改前即失败：`Stale verification evidence: AC-R01-01`。旧 progress 的 verified 不能直接沿用；源指纹覆盖全部核心、测试和活动规格，变化后旧证据按仓库契约保守失效。旧 progress 和初始 diff 保存在 `out/refactor-production/`；历史 evidence 文件原样保留。受影响的旧案例退回 implementing，本轮仅对直接覆盖的证据读取和非法请求恢复案例生成新证据，不把单元测试当作完整客户端、平台或正式比较证明。

执行结果、环境、日志 SHA-256、当前源指纹在 `out/refactor-production/summary.json` 和 `out/handoff.md`。本地 PDF 回归使用 out 下隔离 Python 环境的 pypdf==6.1.1；未安装到全局环境。HTTP 夹具测试通过 `NO_PROXY=* no_proxy=*` 直连回环地址，以免系统代理接管带伪造 Host 的安全测试。无付费模型或正式比较运行。

`make verify` 检验当前本地工程与记录；`make release-check` 仍必须拒绝未完成的产品和比较证据。不能把本轮代码重构称为生产版本或四竞品胜出。
