# product-semantic-bridge：查询期 LLM 语义桥——低覆盖率回退的第三级（动态查询扩展）

- 关联：R04（AC-R04-01 召回质量——本任务不改既有召回语义，只在"即将拒答"路径新增可选扩展）、
  R05（AC-R05-02 LLM 层可选/可配置/产物不入事实——本层只产查询 token，不产任何图事实）、
  R08（有界资源纪律：max_tokens 上限、缓存、失败即跳过不重试风暴）。
- 来源：第一性原理根因链——2026-10-19 量化（dev+public 19 例 miss 中 18 例为检索级：gold 从未进候选）；
  4 轮词法优化 + Plan A + 三方排序 A/B（ab3）全部证明：排序层零效果，候选生成的中英语义鸿沟是
  剩余瓶颈。公共语料 15 例 = 中文查询 vs 英文 README；静态 EN_BRIDGE 词典覆盖有限。
- 立场：默认关闭、只在回退路径末端触发、输出接地（只采纳图中真实存在的索引词）、
  失败/未配置/解析失败一律跳过——**拒答语义与已命中查询零变化**。

## 正例 / 负例

- 正例：`DOMIMAP_SEMANTIC_BRIDGE=1`（或 CLI `query --semantic`）时，**覆盖率 <60% 且查询含
  CJK 单元**的查询经 LLM 生成英文关键词/同义词，过滤到 df 中真实存在的索引词，并入候选
  并集后按既有 BM25 重打分（结果标注语义桥扩展词）。触发门修订（2026-10-22 A/B 前实测）：
  首版触发条件为"仅即将拒答路径"，但 dev 40 题（拒答正例 0）与 pub 97 题图内集（拒答正例 0）
  的 miss 全部是"返回错结果而非拒答"——目标人群为空；放宽为低覆盖（<60%）+中文查询，
  恰为中文查询 vs 英文内容词法鸿沟的实测人群。
- 正例：进程内缓存（查询文本 sha → tokens）+ 可选磁盘缓存，重复查询零重复调用。
- 负例：未启用（默认）时行为与现状逐字节一致；覆盖率 ≥60% 或纯拉丁查询绝不触发本层。
- 负例：无 key / 传输失败 / 响应不可解析 / token 全部不在 df → 跳过本层，拒答文案逐字不变，
  绝不把拒答变假命中（负例底线保持）。
- 负例：LLM 输出是数据不是指令——只接受 token 列表，逐个 df 过滤；不采纳路径/主张/系统提示；
  注入式回复不得改变检索行为（token 之外的一切丢弃）。
- 负例（已知风险，A/B 度量）：扩展词并入弱覆盖查询的计分可能改变既有命中（IDF 稀释教训）；
  A/B 双臂同题对比，若净效果为负则如实记录并回退。

## 实施（精确 allowlist）

1. `domimap/semantic_bridge.py`（新）：`enabled()`/`expand_tokens(text, df, ...)`；复用
   `llm_enrich.LlmClient`（同端点/模型/key 解析与分级重试）；max_tokens 256；缓存。
2. `domimap/search.py`：query() 主计分之后——覆盖率 <60% 且查询含 CJK 单元且启用时，
   语义扩展、df 接地、并集重打分（domain/as_of 资格过滤与主路径一致；<30% 的拒答救援
   路径重算覆盖率）；静态词典桥保留原位原语义（其重打分并入语义词并集）；结果 dict 增
   `semantic_bridge` 键（仅触发时）；拒答文案不变；`semantic` 参数（None=看 env）。
3. `domimap/__main__.py`：`query --semantic` flag。
4. `tests/test_semantic_bridge.py`（新，hermetic 假传输，无网络）：默认关零调用；启用后
   命中；接地过滤；失败/解析跳过；缓存零重复；已命中查询不触发；CLI flag 传递。
5. 文档：docs/knowledge-graph.md 检索数据流补第三级；README 能力矩阵一行。

## 验证与回退

- `python3 -B -m unittest tests.test_semantic_bridge -v` 11 契约全绿；refresh_evidence 后
  `make verify` 全绿（默认关路径零回归由存量契约守护）。
- **真实 A/B（2026-10-22，工件 out/semantic-bridge-ab/，真实 GLM-5.3，~11 次扩展调用）**：
  - dev 40 题检索级回放：基线 19/36 → 桥 19/36（零变化零回归；桥触发 4 次=负例）。
  - pub 图内集 97 正例 + 40 负例：基线 23/97 → 桥 23/97（零变化零回归；桥触发 7 次全为负例，
    接地过滤未产生假命中；负例拒答 11/40 两臂一致，零破坏）。
  - **根因修正（重要）**：74 个图内 miss 的原始查询覆盖率全部 ≥60%（64 中文 + 10 拉丁）——
    miss 机制是"高覆盖下 gold 排不进 top5"的**排序失败**，不是词法召回鸿沟。此前"CN 查询 vs
    EN README 召回鸿沟"的归因来自 agent-loop 评测口径，检索级直查口径下不成立。
  - 如实结论：语义桥对本基准零效果（保留为可选层：真实的低覆盖跨语言查询场景仍有产品价值，
    默认关零成本）；**下一个必要台阶确证为 LLM rerank / embedding 语义重排序**（与
    lane-fusion 三方 A/B 结论一致，且本次提供了覆盖率画像的量化证据）。
