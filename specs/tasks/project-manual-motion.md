# 项目说明书：标题体系、设计问答与动态原理演示

日期：2026-10-25。范围：用户明确将交付定位为项目说明书，并优化题目和可动交互。只修改说明资料，不修改产品行为。

## 关联与输入输出

承接 analysis-interview 的全部 R01–R14/F1-C1–C4/F2–F4 与44案例覆盖。输入为已有说明资料、当前源码/规范快照和真实验证工件；规范与实现的差异保留，不读取确认 gold、私有来源或密钥。

输出保留 `out/project-analysis/index.html` 和 `guide.md` 原入口。标题、页签、目录、章节、问题与解析均采用“项目说明书 / 设计问答”表述；旧版本和工件保存到 archive/v1，并记录哈希与路径迁移映射。新增动画数据、脚本、样式和专用 QA，所有生成物仍在 out 下。

## 动态交互契约

1. 提供检索与读证据、代际发布、知识复核三条原理演示。节点/箭头/移动标记与步骤说明同步；播放、暂停、继续、前后步进、进度定位、速度、重置可用。
2. 动画是合成原理演示，无 API/模型/产品写入；检索返回与用户再读证据是分开的操作。发布在 COMMIT 前不得显示新代 active；中断模拟保留旧 active，并区分临时文件与孤儿。
3. 知识确认/修订/撤回展示不同最终状态，不将审定改为直接抽取。图与问题可跳转到相关演示步骤。
4. 默认静止、用户触发才动；播放到末尾停止。暂停/换场景/切后台/离开可视区域要停止旧动画；prefers-reduced-motion 保留步进，避免强迫连续运动。
5. 保持离线、源码定位、C4/5W2H、全量案例、缩放/平移/导出/问答筛选与打印功能；320–1440px 适配。动画只改变演示层的状态。

## 正例与负例

- 播放时移动标记的位置在不同时间采样确实变化；暂停后位置与阶段不漂移，继续后正确前进，最后一步停止。
- 播放中切换场景或定位步骤，无旧计时器/高亮/状态串入；倍速确实改变运动速度。
- 发布中断分别验证写临时文件、rename 后和事务提交前；active 始终旧代。COMMIT 后才新代；不把中断当成功。
- 三种复核动作分别显示确认绑定/新增修订/撤回，推断类型保持；示例不冒充真实运行日志。
- 同时打开多个图/问题联动时只能有一条主演示播放；减少动态效果偏好、后台页面与打印时无悬挂动画。
- 标题/目录/问题不残留面试题库口吻；来源与规范范围保持。空筛选、长文本、窄屏无整页横向溢出。

精确源码/手写文件见 manifest；生成日志、截图和导出清单在 revision2 summary 中逐项登记。任务相对 HEAD 已有其他未提交工作，使用本次起点文件哈希对照验证边界，不接管旧改动。回退恢复 archive/v1 的资料，不改产品源与基准。交接记录已实施、真实验证、剩余产品案例与下一动作，不升级生产阶段。
