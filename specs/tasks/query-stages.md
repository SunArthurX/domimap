# query-stages — 查询拆成资格与分路融合

日期：2026-10-28。计划 T22 的可执行部分。

## 问题

`Searcher.query` 把拒答、打分、三路融合、重排和渲染写在一个函数里。分路规则改一处就要在嵌套函数里找。

## 预期

- `_keep_candidate` 决定节点是否有资格（被替代、过期、晚于 as_of）。
- `_score_matched` 用当前覆盖率给词法候选打分。
- `_refusal_for_gap` 产生覆盖率不足、域滤空、无强信号三种拒答。
- `_select_hits` 做三路保底、跨文件族替换和可选重排，返回命中列表。
- `query` 仍负责扩词、语义桥、中英桥回退、嵌入融合和渲染。默认关闭重排时，迷你图上的种子 id 与拆分前一致（由既有 golden / lane / BM25 测试锁住）。

## 未包含

语义桥内部的另一套资格判断仍留在 `query` 里，因为它用的是本地时区换算，和主路径的 UTC 零点不是同一套。

## 回滚

把这两个方法的函数体挪回 `query`。
