# product-ui-flow-ux — 页面流程 UX 优化（体验官走查计划）

## 走查方法

以用户旅程五阶段（首次进入 → 输入 → 等待 → 结果消费 → 跨界回场）对工作台逐流程走查，
记录断点，按"断点对任务完成度的影响"排序，只修流程不改视觉基线（Apple 风格保持）。

## 断点与方案（4 项）

1. **首次进入无引导**（首次进入）：新用户面对空输入框无第一步。
   → 检索问答表单下加"快速开始"示例条（3 个真实示例 chip：订单改价 / t_order / 库存预警），
   点击即填即跑；localStorage `dm-wb-seen` 记录使用过的工作流后收起（再次引导不打扰）。
2. **等待无过程感知**（等待）：运行中结果区空白。
   → #out 运行期间渲染 3 行骨架 shimmer（respect prefers-reduced-motion），完成后替换。
3. **跨工作流链路断裂**（结果消费，最核心）：检索到表/方法后想看影响面须手动切工作流重输。
   → 候选行加次级操作按钮：kind∈{Table,Method,Class,Service} 显示"影响面"（跳转影响面工作流、
   预填符号并自动运行）；Doc 保持"点行读证据"；影响面结果行加"检索"回查（跳检索预填符号）。
4. **终端回场无感知**（跨界回场）：命令型提示"刷新页面"，图更新后页面不自察。
   → window focus 时拉 /api/stats，节点/边数与初始注入不一致则顶部显示
   "图已更新（N 节点 / M 边）——点击刷新"提示条，点击整页刷新。

## 契约（不可破坏）

- AC-F2-01 同源同序、AC-R08-02 回环/无注入/CSP 不变；
- 不新增写路径；示例条数据全部来自页面内静态定义（不引入外部请求）。
